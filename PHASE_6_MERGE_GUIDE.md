# Phase 6 merge guide

This is an incremental patch. Merge it on top of the Phase 5 build; do not delete other Phase 2–5 files.

## Replace existing files
- `index.html`
- `styles.css`
- `app.js`
- `collections.js`
- `README.md`
- `SOURCES_AND_LICENCES.md`

## Add new files/folders
- `library-art.js`
- `pwa.js`
- `sw.js`
- `manifest.webmanifest`
- `PHASE_6_QA.md`
- `PHASE_6_MERGE_GUIDE.md`
- `assets/my-studio/*.webp` (8 images generated by you in ChatGPT and selected from your ChatGPT Library)
- `icons/app-192.png` and `icons/app-512.png`

The patch intentionally does not contain `creator.js`, `brand-voice.js`, the Phase 2 art/pose files or any original PNGs. Keep those existing files in place. The eleven generated Library images are optimized local WebP copies; the original Library files remain unchanged.

After upload to an HTTPS host, open the site once online, then reload it while offline to check the cached shell and local Studio artwork. Browser installation support varies by Android browser.
